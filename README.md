# KALD CAFFE — Circle01

أول مشروع منيو إلكتروني لـ Circle01.

تمت إضافة صور تمثيلية لكل صنف باستخدام صور مجانية من Unsplash، لأن صور KALD الأصلية للمنتجات لم تصل بعد. عند وصول صور الكافيه الحقيقية نستبدلها بسهولة.

## الملفات
- `index.html` هيكل الموقع.
- `style.css` التصميم.
- `script.js` عرض المنيو والصور.
- `menu-data.json` بيانات الأصناف والأسعار وروابط الصور.
- `images/` مكان صور KALD الأصلية لاحقًا.

> الصور الحالية تجريبية/تمثيلية وليست صور منتجات KALD الفعلية.


## الصور
تم تضمين صور محلية داخل مجلد `images/` وربطها بملف `menu-data.json` حتى تعمل على GitHub Pages بدون الاعتماد على روابط صور خارجية..
